# Onboarding screenshot capture checklist

Capture these images from the live Google AI Studio page. Do not create placeholder images in the repository.

| File | Exact page to capture | Must be visible | Crop | Light mode | Dark mode |
|---|---|---|---|---|---|
| `step-1.png` | Google AI Studio landing page before key creation | The page identity and the primary entry point for creating an API key | Crop to the main page content; exclude browser chrome and personal account details | Confirm text and controls have sufficient contrast on the light background | Confirm text and controls have sufficient contrast on the dark background |
| `step-2.png` | Google AI Studio terms or privacy step shown before key creation | The terms/privacy checkpoint the user must review | Crop to the terms and required acknowledgement; exclude personal account details | Confirm the acknowledgement and body text are readable | Confirm the acknowledgement and body text are readable |
| `step-3.png` | Google AI Studio API key creation screen | The **Get API key** action | Crop to the key creation control and surrounding context; do not include an existing key | Confirm controls and labels are readable | Confirm controls and labels are readable |
| `step-4.png` | Google AI Studio project selection/key creation confirmation screen | The **Create API key** action and project selection context | Crop to the project selector and create action; do not include an existing key | Confirm controls and labels are readable | Confirm controls and labels are readable |

Before adding each file to `web/public/onboarding/`, verify that no API key, email address, project identifier, or other personal information is visible.
